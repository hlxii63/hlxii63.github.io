🧭 快速上手（3 步）

1️⃣ 画关卡：选工具（⬛ 障碍 / ◎ 枢纽 / 数字 / 红绿边）摆出关卡；再用「┅ 答案路径」画一条连续的路

2️⃣ 放起点终点：点「S 起点」「E 终点」放好，答案路径从 S 到 E 且经过每个普通格一次

3️⃣ 开玩：「▶ 试玩当前关卡」验证 → 「🌐 社区」玩别人的关 / 上传自己的关 → 「⚔️ 对战」双人比拼

❓ 规则与图例

目标：从 起点 S 出发画一条连续路径，经过每个普通格恰好一次（灰色格可以不经过），最后到达 终点 E。

S起点：路径的第一个格子（可与枢纽/斜向/灰格叠加）
E终点：路径的最后一个格子（可与枢纽/斜向/灰格叠加；只需最终到达）
⬛障碍格：不能进入
◎枢纽：至少经过一次，可多次经过
╳斜向连线格：可以斜向进入/离开
⬜灰色格：可以不经过；若经过则最多一次。可与枢纽、斜向、起终点叠加
5数字格：路径第 5 个格子必须是它（第 1 个 = 起点）。填两个数 a~b 表示「第 a~b 步之间到达该格」即可。可与终点/斜向/灰格重合，不可与枢纽重合
◎╳斜向枢纽 = 枢纽 + 斜向格（可多次经过且可斜向）
—红边：路径禁止跨越
—绿边：路径必须跨越（至少一次）
┅答案路径（灰色虚线）：编辑器中用「答案路径」工具绘制，试玩时隐藏；关卡必须有有效答案才能游玩

操作：编辑器里选好工具后点击格子；红/绿边先点一格再点相邻格（含斜向）；数字格先在「数字」输入框填范围（两个框都填 = 区间 a~b，只填第一个 = 精确步数；都留空点击可移除数字）再点格子；答案路径从 S 开始点或拖动画线（与试玩规则相同），可用「撤销一步答案」逐步回退；试玩时从 S 开始点或拖动画线，可撤销一步/十步、可显示序号。

PC 端移动地图：按住 右键/中键 拖动即可平移（或点左上角 ✋ 切换拖动模式后用左键拖）；方向键 也能平移（Shift 加速）；Shift+滚轮 或触控板横向滑动 = 左右平移，普通滚轮 = 缩放，Ctrl+滚轮 = 缩放。

隐藏答案：编辑器默认「隐藏答案路径」（勾选状态），载入示例/导入关卡时不会显示灰色虚线官方解，防止偷看；取消勾选即可查看；绘制答案时会自动临时显示。

难度：可填「前缀 + 难度」（如 FATE 17.0），导出后随关卡保存。

限时与评级：编辑器「限时」填秒数（0 = 不限时）。限时关按 实际用时 ÷ 限时 评 Phi(≤100%) / V(≤120%) / S(≤150%) / A(≤200%) / B(≤500%) / C(>500%)；看过答案或不限时的完成 = Phi；未完成/看答案后放弃 = F。实力系统中：限时关 Phi = 难度+1、V = +0.5、S = 难度本身、A = −0.5、B = −1、C = −2（区间内线性插值，负数归 0）；不限时关 Phi = 难度本身。

背景音乐：点编辑器「🎵 音乐库」→ 填名称 + 音频直链 URL（形如 https://…/a.mp3，必须是能直接下载的音频地址，不是网页地址）→ ＋添加 → 系统自动分配 ID（如 m1a2b）→ 在编辑器「音乐」框填这个 ID 即可。首次播放会自动下载并缓存到本机，之后不再重复下载；在音乐库里可试听 / 删除下载缓存 / 删除条目，也可调音量。保存/导出关卡时会自动带上对应 URL，所以分享给别人也能听到（对方首次打开会自动下载缓存）。

列表进度与计时：列表有总计时（状态栏与列表面板每秒刷新）。点「📋 返回列表」或「⏸ 暂停并保存」会冻结计时并保存进度，之后点「▶ 继续」接着计时（关闭页面/刷新也不会丢，且不计算关闭期间的时间）；「🔄 重新开始」清空进度但保留累计时长，「✕ 放弃列表」才作废。社区列表同样有排行榜（按首次通关时间排名，显示用时）与点赞。

社区列表：在「📋 列表」标签页点某列表的「⬆」即可上传到社区（关卡数据内嵌，别人不用先下载关卡就能玩）；社区里用「📋 社区列表」按钮查看，与关卡列表分开；开发者可给列表评级 / 精选。

关卡列表：「🗂️ 关卡库 → 📋 列表」可把本地关卡编成一串（可以包含无解关卡）。列表内关卡不能查看答案、不能进编辑器、不能单关限时；列表可设总时长。可把某几关设为初始隐藏（列表中不显示），并用条件让它出现：2*a3 + a5 >= 7 => 显示 4。其中 aK = 该关第 K 格「从上到下、每行从左到右」被经过的次数（第 1 格起，例：6×6 的第 2 行第 3 列 = 第 9 格），未通关则该关所有 aK 记 0；运算符 = < <= > >= <>；动作写「显示 N / 隐藏 N」（N = 列表内关卡序号）。必须完成🏁 最终关卡才算通关列表；「重新开始」清空列表进度但保留累计游玩时长。

关卡库：「🗂️ 关卡库」可把当前关卡保存到本机（成品或半成品草稿，下次继续编辑），也可上传到社区共享。社区有两种方式：自建服务器（server/community-server.js 或 CloudBase 云函数）或 GitHub Gist 免服务器方案（在 GitHub 新建一个含 levels.json 的 Gist，读取免 Token，上传/删除需要 GitHub Token）。

进阶挑战：示例里内置 8×8「进阶挑战」超级难题（难度 15.2），含斜向枢纽、红绿边与数字格约束，试试看你能不能通关。

答案加密：导出 JSON 时答案以加密形式存储（solutionEnc），不会出现明文；导入时自动解密。

密码：「🔒 密码」可为关卡设置密码；导入关卡默认进入试玩，进入编辑器需输入密码（密码以加盐哈希加密存储，不保存明文）。

通关：到达 E 且所有普通格恰好一次、枢纽 ≥1 次、所有绿边均被跨越。

禁止折返：不能从枢纽的某个方向出去后，又从同一方向立刻回来（X→枢纽→X→枢纽 不允许，含斜向）；从不同方向绕回枢纽是允许的。
