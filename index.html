❓ 规则与图例

排行榜用时：榜上的「初见」= 初见总用时（从第一次打开这一关到首次通关的全部净时长，退出/清空/踩重置都不清零）。评级仍按「本轮用时」算。

目标：从 起点 S 出发画一条连续路径，经过每个普通格恰好一次（灰色格可以不经过），最后到达 终点 E。

S 起点：路径的第一个格子（可与枢纽/斜向/灰格叠加）
E 终点：路径的最后一个格子（可与枢纽/斜向/灰格叠加；只需最终到达）
⬛ 障碍格：不能进入
◎ 枢纽：至少经过一次，可多次经过
╳ 斜向连线格：可以斜向进入/离开
⬜ 灰色格：可以不经过；若经过则最多一次。可与枢纽、斜向、起终点叠加
5 数字格：路径第 5 个格子必须是它（第 1 个 = 起点）。填两个数 a~b 表示「第 a~b 步之间到达该格」即可。可与终点/斜向/灰格重合，不可与枢纽重合
◎╳ 斜向枢纽 = 枢纽 + 斜向格（可多次经过且可斜向）
— 红边：路径禁止跨越
— 绿边：路径必须跨越（至少一次）
— 蓝边：这段连线允许重复经过（放行「同一段不能走两次」的判定），但不能刚过去就原路返回；斜向蓝边需要两格都是斜向格才画得出
┅ 答案路径（灰色虚线）：编辑器中用「答案路径」工具绘制，试玩时隐藏；关卡必须有有效答案才能游玩

操作：编辑器里选好工具后点击格子；红/绿边先点一格再点相邻格（含斜向）；数字格先在「数字」输入框填范围（两个框都填 = 区间 a~b，只填第一个 = 精确步数；都留空点击可移除数字）再点格子；答案路径从 S 开始点或拖动画线（与试玩规则相同），可用「撤销一步答案」逐步回退；试玩时从 S 开始点或拖动画线、可显示序号。

上传关卡：本地关卡通关后，结算页有 ⬆ 上传关卡 按钮（这是唯一的上传入口），登录社区账号后即可把这一关分享到社区；社区关卡本身已经在社区里，结算页不再显示这个按钮。

进度保存：试玩中途切后台、关页面、被系统回收，进度都会自动存下来（当前笔画、已完成笔画、暂停笔画、草稿线、用时、机关与物体的位置/得分/动画），下次进来接着走；也可点 ⏏ 返回编辑手动存档。

往回走（撤销）：试玩时点路径上的上一格即往回退一步（按住拖动拖回上一格也可以连续退），可以连续点、连续拖、连续退。撤销有两种模式，在「关卡设置 · 撤销方式」里选：
· 原版撤销（默认）：时间和物体一起回到那一刻——计时倒退到那一步的用时，按钮、得分、机关、视野也全部还原；正在移动中的物体从那一刻继续往下走（和「退出游玩时保存进度」用的是同一套整局恢复逻辑，不会一下子弹回起点）。
· 仅回退：只把路径退回去，计时继续走，物体停在原处不回退（得分、机关状态也保持现状）。
关卡设置里关掉「允许往回走」后就不能回退，只能点 🧹 清空路径 重开。

物体分组（group）：每个物体都可以填「分组」，一个物体可以同时属于多个分组（逗号分隔，如 enemy,wall）。按钮动作的「目标」除了 按ID、按格子，还有 按分组：填一个或多个分组名，触发时把这一组的物体一次性全部处理（移动、删除、禁用、隐藏、显示、启用），不用一个个填编号；「在指定格生成物体」时也能顺便写上分组，生成出来的物体直接归到这一组。

删除物体 · 灰格也是物体：灰色格、障碍、枢纽、斜向格、数字格、起终点、红/绿/蓝边都是真正的物体，各有自己的 #编号（编辑器物体面板里能看到），所以既能用「🗑 删除物体」删，也能被动作「删除物体 + 按格子 / 按分组」删掉。动作指向某个灰格时会把灰格从格子上抹掉（之后就是普通格，可以正常重复经过）；擦除工具同样能擦灰格。

雾霾 / 视野：🌫 雾霾只遮挡画面，不影响判定；「视野」可定义若干矩形范围（写法 id,行,列,宽,高，多条用 ; 分隔），锁定后棋盘只显示那一块、路径也只能画在里面，按钮可用「设置视野范围」动作随时切换或解除。

草稿 / 亚像素 / 批量：试玩页「📝 打草稿」点两个相邻格（含斜向）画一条灰色短线段做提示，不参与判定、对战也能用；「修改格子亚像素」把一个格子切成 6×6 小格逐个上色，可以作画；编辑器按住拖动可批量放物体（设置里「拖动批量」可选「刷子（轨迹）」或「矩形填充」）。

PC 端移动地图：按住 右键/中键 拖动即可平移（或点左上角 ✋ 切换拖动模式后用左键拖）；方向键 也能平移（Shift 加速）；Shift+滚轮 或触控板横向滑动 = 左右平移，普通滚轮 = 缩放，Ctrl+滚轮 = 缩放。

隐藏答案：编辑器默认「隐藏答案路径」（勾选状态），载入示例/导入关卡时不会显示灰色虚线官方解，防止偷看；取消勾选即可查看；绘制答案时会自动临时显示。

难度：可填「前缀 + 难度」（如 FATE 17.0），导出后随关卡保存。

限时与评级：编辑器「限时」填秒数（0 = 不限时）。限时关按 实际用时 ÷ 限时 评 Phi(≤100%) / V(≤120%) / S(≤150%) / A(≤200%) / B(≤500%) / C(>500%)；看过答案或不限时的完成 = Phi；未完成/看答案后放弃 = F。实力系统中：限时关 Phi = 难度+1、V = +0.5、S = 难度本身、A = −0.5、B = −1、C = −2（区间内线性插值，负数归 0）；不限时关 Phi = 难度本身。

背景音乐（两种方式）：① 上传文件：音乐库里选文件 →「⬆ 上传到社区音乐库」（需登录），系统自动分块写入社区仓库并分配 ID（每块 700KB，单曲上限 30MB，块信息写在文件名 …p1ofN… 里），别人播放时自动逐块下载拼回并缓存。② 外链 URL：编辑器「🎵 音乐库」→ 填名称 + 音频直链（形如 https://…/a.mp3，必须是能直接下载的音频地址，不是网页地址）→ ＋添加（自动分配 ID，如 m1a2b）→ 在编辑器「音乐」框填这个 ID。首次播放自动下载并缓存，之后不再重复下载；音乐库里可试听 / 删除下载缓存 / 删除条目 / 调音量。保存或导出关卡时会自动带上对应 URL，分享给别人也能听到。

建议评级（玩家）：通关后结算浮层会出现「💬 建议评级（难度）」输入框，填一个数（如 12.5）提交即可；这会显示在关卡的排行榜上（榜头还会显示「玩家建议评级：平均 X（N 人评过）」），并且本人可以在排行榜自己那一行直接修改或取消（填 0 或留空＝取消）。建议评级只代表玩家意见，不会改变成绩（用时与过程仍以第一次记录为准），也不会改掉作者设定的难度。

排行榜：关卡的成绩以第一次记录为准——名次按首次通关时间，用时与过程之后不再变化（仅旧版缺失字段会补存一次），避免靠重复通关刷时间。

排行榜 · 现代关卡：有机关、时间驱动、没有官方答案路径的关卡同样计入排行榜（只要没看过答案、没进过编辑器）。成绩会连每一步的时间点一起保存，榜上点 ▶ 回放 就按真实时间重放，机关移动、视野切换、得分变化都会如实重现——和自己当初玩的一模一样。

排行榜 · 排序：榜头可切换 得分优先（得分 → 初见总时长 → 完成时刻）与 完成时刻（谁先通关谁在前）；#0 正攻手法 始终置顶，不参与排序。

关卡库：「🗂️ 关卡库」可把当前关卡保存到本机（成品或半成品草稿，下次继续编辑），也可上传到社区共享。社区有两种方式：自建服务器（server/community-server.js 或 CloudBase 云函数）或 GitHub Gist 免服务器方案（在 GitHub 新建一个含 levels.json 的 Gist，读取免 Token，上传/删除需要 GitHub Token）。

进阶挑战：示例里内置 8×8「进阶挑战」超级难题（难度 15.2），含斜向枢纽、红绿边与数字格约束，试试看你能不能通关。

答案加密：导出 JSON 时答案以加密形式存储（solutionEnc），不会出现明文；导入时自动解密。

密码：「🔒 密码」可为关卡设置密码；导入关卡默认进入试玩，进入编辑器需输入密码（密码以加盐哈希加密存储，不保存明文）。

通关：到达 E 且所有普通格恰好一次、枢纽 ≥1 次、所有绿边均被跨越。

禁止折返：不能从枢纽的某个方向出去后，又从同一方向立刻回来（X→枢纽→X→枢纽 不允许，含斜向）；从不同方向绕回枢纽是允许的。
